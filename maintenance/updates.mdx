| Platform | How to update |
| --- | --- |
| Mac / Windows | Download the new installer. Install over the old app. |
| StartOS | Sideload the new `.s9pk`. |
| Umbrel | Run `./install.sh` from the new bundle. |

The desktop app shows a notice when a new version exists. It does not update itself.

Your data stays during updates. Back up first anyway.

<Tip>After an update, fully quit and reopen the app.</Tip>
