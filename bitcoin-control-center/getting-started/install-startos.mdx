Control Center is in the **Start9 Community Registry**. Install it from the StartOS **Marketplace**. It needs StartOS 0.4.0.2 or later.

## Before you start

Install and fully sync these StartOS services. Control Center needs all of them running.

| Service | Why it is needed |
| --- | --- |
| **Bitcoin** | Your node. |
| **Electrs** | Wallet balances and transaction history. |
| **Mempool** | Bitcoin prices and transaction details for statements. |

<Warning>If Electrs is stopped or still syncing, Control Center may not start. Wait for Electrs to finish first.</Warning>

## Install

<Steps>
  <Step title="Open the Community Registry">
    In StartOS, open **Marketplace**. Switch the registry to the **Start9 Community Registry**.
  </Step>
  <Step title="Install">
    Find **Bitcoin Control Center**. Select **Install**.
  </Step>
  <Step title="Set your PIN">
    StartOS shows a task: **Set a PIN before using Bitcoin Control Center**. Run **Set PIN**. Enter 6 digits twice. Save it in your password manager.
  </Step>
  <Step title="Open it">
    Start the service. Open **Web Interface**.
  </Step>
  <Step title="Sign in">
    Enter your PIN.
  </Step>
</Steps>

<Note>The PIN works only over `https://` or the `.onion` address. Over plain `http://`, you see **Insecure connection not allowed**.</Note>

## Options

In StartOS, open Control Center → **Actions** → **Configure**. Saving restarts the service.

- **Mempool URL Override:** leave blank to use your Mempool service. Enter a URL to use another Mempool instance.
- **Log Level:** keep **Info** unless support asks for **Debug**.

StartOS has no Electrum or Tor settings in the app. It always uses your Electrs.

## Forgot your PIN?

Run **Set PIN** again. Your accounts and history stay. Everyone is signed out. See [PIN and lock](/bitcoin-control-center/security/pin).

## Back up

Use the normal StartOS backup. It saves everything. See [Backup and restore](/bitcoin-control-center/maintenance/backup-restore).

## Advanced: sideload the package

Only sideload if support asks you to. Download the `.s9pk` from [bitcoincontrolcenter.com](https://www.bitcoincontrolcenter.com). Sideload it in StartOS.

Already sideloaded an earlier version? [Back up](/bitcoin-control-center/maintenance/backup-restore) before you switch to the registry version.
