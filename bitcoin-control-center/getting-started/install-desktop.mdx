## Requirements

- **Mac:** Apple Silicon (M1 or later), macOS 13 or later. Intel Macs are not supported.
- **Windows:** 64-bit (x64).

## Download

Download the installer from [bitcoincontrolcenter.com](https://www.bitcoincontrolcenter.com).

<Tip>Download only from bitcoincontrolcenter.com.</Tip>

## Install

<Tabs>
  <Tab title="Mac">
    1. Open the `.dmg`. Drag the app to **Applications**.
    2. Open **Bitcoin Control Center**. Select **Open** if asked.
  </Tab>
  <Tab title="Windows">
    1. Run the installer. You can choose the install folder.
    2. If SmartScreen appears, select **More info** → **Run anyway**. The installer is not publisher-signed yet.
  </Tab>
</Tabs>

## First launch

1. Set a 6-digit PIN. See [PIN and lock](/bitcoin-control-center/security/pin).
2. Follow the short introduction, or select **Skip**.
3. Choose your Electrum server. See [First run](/bitcoin-control-center/getting-started/first-run).

## Closing versus quitting

Closing the window does **not** quit the app. It keeps running in the menu bar (Mac) or system tray (Windows) and locks.

| You want to | Do this |
| --- | --- |
| Hide the window | Close it. You need your PIN to open it again. |
| Show it again | Click the tray icon, or select **Show Control Center**. |
| Quit fully | Select **Quit** from the tray menu, or press **Cmd+Q** on Mac. |

Quit fully before you [back up](/bitcoin-control-center/maintenance/backup-restore) or [update](/bitcoin-control-center/maintenance/updates).

Only one copy runs at a time. Opening it again brings up the existing window.
