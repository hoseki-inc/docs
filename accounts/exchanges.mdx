Control Center connects with an **API key** you create on the exchange.

## Steps

1. On the exchange, create an API key with **view / read-only** access. Do not allow trading or withdrawals.
2. In Control Center, open **Accounts** → **Add Account** → your exchange.
3. Paste the key fields. Select **Connect**.

| Exchange | What you paste |
| --- | --- |
| Coinbase | API key name and private key |
| Kraken | API key and secret |
| Robinhood | API key and private key |
| Strike | API key |

Keys are encrypted and stored on your device only.

## Strike statements

If a Strike statement needs a CSV, export it in Strike from **Activity** → **Generate Report**.
