Control Center imports **public** keys (xpubs) only. Your coins stay on your wallet.

## Supported

| Wallet | How it connects |
| --- | --- |
| Ledger | USB |
| Trezor | USB |
| Coldcard | MicroSD file or QR code |
| Keystone | QR code |
| Multisig | Descriptor file, then sign on each device |

## Advanced manual signing

Attach a single-signature wallet by pasting its account descriptor or extended public key, then signing a message on the device. That proves you control the key.

**Manual Entry** only stores a balance you type. See [Manual Bitcoin and ETFs](/accounts/manual-and-etfs).

Open **Accounts** → **Add Account**. At the bottom, expand **Advanced** → **Manually Verify Your Self-Custodial Bitcoin Holdings**. Select **Verify with Manual Signing**. The next screen is labeled **Advanced Feature**.

1. Enter a **Display name**.
2. Paste an **Account descriptor or extended public key** (xpub, ypub, or zpub). Prefer a descriptor. It already includes the script type.
3. If you paste an xpub, select the script type: **Legacy (P2PKH)**, **Nested SegWit (P2SH)**, **Native SegWit (P2WPKH)**, or **Taproot (P2TR)**.
4. Select **Add Account**.
5. Copy the **Address** and **Message**. Sign that message with your wallet's message-signing tool.
6. Paste the result into **Signature**. Select **Verify**.

On Coldcard, if you have no MicroSD card, select **verify manually**. That opens this same path.

<Note>Advanced manual signing works for a single-signature wallet only.</Note>

## Multisig

On **Add Account**, pick **Multisig**. Upload your descriptor file, or paste it. Then sign on each hardware wallet. You can sign the keys in any order.

<Warning>
Advanced manual signing is unavailable for multisig. A multisig proof needs a signature from each required key, on the device. Many wallets do not support BIP322 yet, so you cannot paste one message signature for a multisig setup.

On a multisig device check, **Advanced** opens **Show Technical Details**. That is not manual signing.
</Warning>

## USB tips

- Use a Chromium browser (Chrome, Brave, Edge) on StartOS or Umbrel.
- Close other wallet apps first.

<Warning>Never type your seed phrase into Control Center. Approve each signature on your hardware wallet.</Warning>
