## Before you start

Install and fully sync **Bitcoin**, **Electrs**, and **Mempool**.

<Frame caption="All three must be running. Screenshot coming soon.">
  <img
    src="/images/install-startos-dependencies.png"
    alt="StartOS services list with Bitcoin, Electrs, and Mempool running"
  />
</Frame>

<Steps>
  <Step title="Sideload the package">
    Download the `.s9pk` from [GitHub Releases](https://github.com/hoseki-inc/bitcoin-control-center/releases). Sideload it in StartOS.

    <Frame caption="Sideload the .s9pk file. Screenshot coming soon.">
      <img
        src="/images/install-startos-sideload.png"
        alt="StartOS sideload screen with the Bitcoin Control Center .s9pk selected"
      />
    </Frame>
  </Step>
  <Step title="Set your PIN">
    Run **Set PIN**. Pick 6 digits. Save it in your password manager.

    <Frame caption="The Set PIN action. Screenshot coming soon.">
      <img
        src="/images/install-startos-set-pin.png"
        alt="StartOS Set PIN action for Bitcoin Control Center"
      />
    </Frame>
  </Step>
  <Step title="Open it">
    Start the service. Open **Web Interface**.

    <Frame caption="Open the Web Interface. Screenshot coming soon.">
      <img
        src="/images/install-startos-web-interface.png"
        alt="Bitcoin Control Center service page in StartOS with Web Interface button"
      />
    </Frame>
  </Step>
  <Step title="Sign in">
    Enter your PIN.

    <Frame caption="Enter your 6-digit PIN. Screenshot coming soon.">
      <img
        src="/images/install-startos-pin-entry.png"
        alt="Control Center PIN sign-in screen"
      />
    </Frame>
  </Step>
</Steps>

<Note>The PIN works only over `https://` or the `.onion` address.</Note>

Forgot your PIN? Run **Set PIN** again. Your data stays. Everyone is signed out.
