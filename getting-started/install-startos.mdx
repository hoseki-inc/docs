## Before you start

Install and fully sync **Bitcoin**, **Electrs**, and **Mempool**.

<Steps>
  <Step title="Sideload the package">
    Download the `.s9pk` from [GitHub Releases](https://github.com/hoseki-inc/bitcoin-control-center/releases). Sideload it in StartOS.
  </Step>
  <Step title="Set your PIN">
    Run **Set PIN**. Pick 6 digits. Save it in your password manager.
  </Step>
  <Step title="Open it">
    Start the service. Open **Web Interface**.
  </Step>
  <Step title="Sign in">
    Enter your PIN.
  </Step>
</Steps>

<Note>The PIN works only over `https://` or the `.onion` address.</Note>

Forgot your PIN? Run **Set PIN** again. Your data stays. Everyone is signed out.
