Control Center reads balances from an **Electrum server**. Your choice affects privacy.

## Pick a server

- **Your own node (best):** Electrs, Fulcrum, or Electrum Personal Server.
- **Public server:** Works, but the operator can see which addresses you check.

StartOS and Umbrel connect to your Electrs automatically.

## Desktop: connect

- **Host and port:** from your server. SSL often uses `50002`. Plain TCP often uses `50001`.
- **SSL:** use it for any server not on your own network.
- **Tor:** the desktop app includes Tor for `.onion` servers.
