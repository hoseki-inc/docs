<Info>Control Center is not in the Umbrel App Store yet. Sideload it for now.</Info>

## Before you start

Install and sync **Bitcoin Node**, **Electrs**, and **Mempool**.

<Frame caption="All three apps installed. Screenshot coming soon.">
  <img
    src="/images/install-umbrel-dependencies.png"
    alt="Umbrel home with Bitcoin Node, Electrs, and Mempool installed"
  />
</Frame>

<Steps>
  <Step title="Get the bundle">
    Download the Umbrel sideload bundle from [GitHub Releases](https://github.com/hoseki-inc/bitcoin-control-center/releases). Copy it to your Umbrel.
  </Step>
  <Step title="Run the installer">
    SSH in as `umbrel`. Extract the bundle. Run:

    ```bash
    ./install.sh
    ```

    <Frame caption="A successful install. Screenshot coming soon.">
      <img
        src="/images/install-umbrel-terminal.png"
        alt="Terminal running install.sh on Umbrel with success message"
      />
    </Frame>
  </Step>
  <Step title="Open it">
    Open **Bitcoin Control Center** from the Umbrel home screen.

    <Frame caption="Find it on the home screen. Screenshot coming soon.">
      <img
        src="/images/install-umbrel-home.png"
        alt="Bitcoin Control Center icon on the Umbrel home screen"
      />
    </Frame>
  </Step>
  <Step title="Set your PIN">
    Pick 6 digits. Save it in your password manager.

    <Frame caption="Create your PIN. Screenshot coming soon.">
      <img
        src="/images/install-umbrel-set-pin.png"
        alt="Control Center set PIN screen on first open"
      />
    </Frame>
  </Step>
</Steps>

To update, run `./install.sh` from the new bundle. Uninstall from Umbrel's app menu.

Forgot your PIN? In Umbrel's terminal, run:

```bash
sudo docker exec bitcoin-control-center_web_1 node /app/dist/cli.js reset-pin
```

Then set a new PIN on next open. Your data stays.
