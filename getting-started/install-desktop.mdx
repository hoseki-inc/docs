## Requirements

- **Mac:** Apple Silicon (M1 or later), macOS 13 or later. Intel Macs are not supported.
- **Windows:** 64-bit (x64).

## Install

<Tabs>
  <Tab title="Mac">
    1. Download the `.dmg` from [GitHub Releases](https://github.com/hoseki-inc/bitcoin-control-center/releases).
    2. Open it. Drag the app to **Applications**.
    3. Open **Bitcoin Control Center**.
  </Tab>
  <Tab title="Windows">
    1. Download the installer from [GitHub Releases](https://github.com/hoseki-inc/bitcoin-control-center/releases).
    2. Run it.
    3. If SmartScreen appears, select **More info** → **Run anyway**. The installer is not publisher-signed yet.
  </Tab>
</Tabs>

Next: [First run](/getting-started/first-run).

<Tip>Download only from GitHub Releases or bitcoincontrolcenter.com. Each release lists checksums.</Tip>
