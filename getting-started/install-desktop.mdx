## Requirements

- **Mac:** Apple Silicon (M1 or later), macOS 13 or later. Intel Macs are not supported.
- **Windows:** 64-bit (x64).

## Download

Get the installer from [GitHub Releases](https://github.com/hoseki-inc/bitcoin-control-center/releases).

  <img
    src="/images/install-desktop-releases.png"
    alt="GitHub Releases page listing Mac DMG and Windows installer downloads"
  />
</Frame>

## Install

<Tabs>
  <Tab title="Mac">
    1. Open the `.dmg`. Drag the app to **Applications**.

    <Frame caption="Drag to Applications. Screenshot coming soon.">
      <img
        src="/images/install-desktop-mac-dmg.png"
        alt="Mac DMG window with Bitcoin Control Center icon and Applications folder"
      />
    </Frame>

    2. Open **Bitcoin Control Center**. Select **Open** if asked.

    <Frame caption="Confirm the first open. Screenshot coming soon.">
      <img
        src="/images/install-desktop-mac-open.png"
        alt="macOS dialog confirming you want to open Bitcoin Control Center"
      />
    </Frame>
  </Tab>
  <Tab title="Windows">
    1. Run the installer.

    <Frame caption="The Windows installer. Screenshot coming soon.">
      <img
        src="/images/install-desktop-windows-installer.png"
        alt="Windows installer for Bitcoin Control Center"
      />
    </Frame>

    2. If SmartScreen appears, select **More info** → **Run anyway**. The installer is not publisher-signed yet.

    <Frame caption="More info, then Run anyway. Screenshot coming soon.">
      <img
        src="/images/install-desktop-windows-smartscreen.png"
        alt="Windows SmartScreen with More info and Run anyway highlighted"
      />
    </Frame>
  </Tab>
</Tabs>

<Tip>Download only from GitHub Releases or bitcoincontrolcenter.com. Each release lists checksums.</Tip>
