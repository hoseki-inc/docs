## Requirements

- **Mac:** Apple Silicon (M1 or later), macOS 13 or later. Intel Macs are not supported.
- **Windows:** 64-bit (x64).

## Download

Get the installer from [GitHub Releases](https://github.com/hoseki-inc/bitcoin-control-center/releases).

## Install

<Tabs>
  <Tab title="Mac">
    1. Open the `.dmg`. Drag the app to **Applications**.
    2. Open **Bitcoin Control Center**. Select **Open** if asked.
  </Tab>
  <Tab title="Windows">
    1. Run the installer.
    2. If SmartScreen appears, select **More info** → **Run anyway**. The installer is not publisher-signed yet.
  </Tab>
</Tabs>

Next: [First run](/getting-started/first-run).

<Tip>Download only from GitHub Releases or bitcoincontrolcenter.com. Each release lists checksums.</Tip>
